# Roadmap

Each step ends with something usable on its own. The flows each step delivers are described in [flows.md](flows.md).

| Step                | Delivers                                                                                                                            | Done when                                                               |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 1. Publish and read | Schema, R2 storage, renderer and typography, `publish`, `read`, `list` over MCP and `/api/v1`, the library, revision history, diffs | An agent publishes a document and you read it on desktop and phone      |
| 2. Review           | Selection to thread and suggestion, draft and submitted reviews, the review MCP tools, anchor relocation                            | A full review round trip with an agent, including an applied suggestion |
| 3. Share            | Share links, guest sign-in, link previews, the settings page                                                                        | A guest signs in from a link, comments, and the agent reads it          |
| 4. Rich content     | `::graph-*` directives, the `mockup` block, PDF export                                                                              | An agent draws an interface proposal that renders in the page           |
| 5. Migrate          | Import of existing GitHub gists as documents                                                                                        | Every current gist lives in evergarden with its history                 |
