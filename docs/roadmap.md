# Roadmap

Each step ends with something usable on its own. The flows each step delivers are described in [flows.md](flows.md).

| Step                | Delivers                                                                                                                                                                              | Done when                                                                                              |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 1. Publish and read | Schema, content storage, renderer and typography, `publish`, `update`, `read`, `list`, `search` over MCP and `/api/v1`, the library with folders, the document page, the version list | An agent publishes a document into a folder and you read it on desktop and phone                       |
| 2. Comment          | Comments on text, blocks and points in figures, replies, suggestions, resolving, relocation after an update, the comment MCP tools                                                    | You comment on all three kinds, the agent answers, updates, and every comment lands in the right place |
| 3. Share            | Share links for documents and folders, guest sign-in, link previews, the settings page                                                                                                | A guest signs in from a link, comments, and the agent reads it                                         |
| 4. Rich content     | `::graph-*` directives, the `mockup` block, PDF export                                                                                                                                | An agent draws an interface proposal that renders in the page and takes pins                           |
| 5. Migrate          | Import of existing GitHub gists as documents                                                                                                                                          | Every current gist lives in evergarden with its history                                                |
